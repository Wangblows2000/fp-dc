# Asset Pipeline

```
user install (read-only)                 extracted/ (gitignored)          converted/ (gitignored)        build/disc/data -> CDI
  Assets.dat ── fp-assets.py -x ──────▶  assets/images/img_N.png  ──┐
                                          assets/images/img_N_meta.txt├─ tools/convert.py ─▶ *.tex *.spr *.lvl
                                          assets/audio/audio_N.ogg ──┤   (slice_manifest.json)  sfx_*.wav *.pcm
  Data/BGM/*.ogg ────────────────────────────────────────────────────┘                         manifest.json
  data/test1.txt (original, generated by tools/make_test_level.py) ──┘
```

## Commands
```sh
# 1. extract (35 s). Refuses to overwrite an existing output dir.
python3 third_party/fp-assets/fp-assets.py -x -f "<game>/Assets.dat" extracted/assets
# 2. level + convert (deterministic; ffmpeg -bitexact)
python3 tools/make_test_level.py
python3 tools/convert.py extracted/assets "<game>/Data/BGM" converted      # add --no-music to skip the 15 MB PCM
# Or: make data FP_GAME="<game>"
```

## Identification helpers
- `tools/contact_sheet.py <img_dir> <out> <start> <end> [per] [cell]`: numbered thumbnails
- `tools/palette_find.py <img_dir> <ref_ids> <thr> <out>`: images sharing a character's palette
- `tools/strip.py <img_dir> <out.png> <ids> [scale] [cols]`: enlarged frames with hotspot marked

## Formats (little-endian)
| File | Layout |
|---|---|
| `.tex` | `FPTX` u16 w, h (pow2), fmt (0 = ARGB1555), srcw, srch, pad; then w·h u16 texels, row-major, non-twiddled |
| `.spr` | `FPSB` u16 nframes, nanims, texw, texh; frames {u16 u, v, w, h; s16 hx, hy}; anims {char[16] name; u16 first, count, speed, loop}; u16 seq[] |
| `.lvl` | `FPLV` u16 w, h, nobj, pad; u8 tiles[w·h]; objs {u16 type; s16 x, y; u16 pad} |
| `sfx_*.wav` | PCM16 mono 22,050 Hz (KOS `snd_sfx_load`) |
| `*.pcm` | raw s16le stereo 22,050 Hz (streamed) |

Tile codes: 0 empty, 1 solid, 2 45°↗, 3 45°↘, 4 one-way, 5 spikes, 6/7 22.5°↗ low/high, 8/9 22.5°↘ high/low.
Object codes: 1 player start, 2 crystal, 3 hornet, 4 checkpoint, 5 goal.

## Validation (in convert.py and the loaders)
- Converter: atlas packing must fit 1024², textures ≤1024², VRAM total must stay under 6 MB (else exit 2), exactly one player start, unknown level chars rejected. Writes sha256 of every output to `manifest.json`.
- Runtime loaders (`src/resources/assets.c`): magic, header sizes, frame rects inside the atlas, anim seq indices < nframes, tile codes < T_COUNT, file size bounds.

## Front end, audio (2026-10-22, D-013/D-014; outputs gitignored)
```sh
G="/mnt/user-data/uploads/Freedom Planet/game"          # read-only copy of the user's install
python3 tools/import_ui.py build/frames extracted/linux/images converted2/ui title 3 4 3+titlestar_53   # press start (+ runtime title stars) + hub
python3 tools/import_ui.py build/frames extracted/linux/images converted2/ui chsel 7      # character select
python3 tools/import_ui.py build/frames extracted/linux/images converted2/ui stsel 12     # Time Attack stage select
python3 tools/import_font.py "$G/Data/font.bmp" converted2/ui                             # 8x20 original font
python3 tools/audio/catalog.py "$G/Data/BGM" "$G/Data/voices" extracted/linux/audio build/audio/catalog.csv
tools/audio/convert_bgm.sh "$G/Data/BGM" converted2/bgm          # 67 x .adp + bgm_manifest.csv
tools/audio/convert_sfx.sh extracted/linux/audio "$G/Data/voices" converted2/sfx   # s<id>.wav + lilac_*.wav
python3 tools/audio/adpcm_check.py <wav> <adp>                     # round-trip SNR (AICA-accurate decoder)
```

Note: the original's `on_frame_N` is `set_frame(N-1)` (DV1 = set_frame 20 = frame_21.json).
